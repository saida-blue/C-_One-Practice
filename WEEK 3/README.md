# Chapter 3: Making Decisions

This project presents selected code examples from Chapter 3 of *Starting Out with Programming Logic and Design / C#* by Tony Gaddis. The chapter explains how a program chooses what to do based on conditions.

## Chapter overview

The examples cover relational and logical operators, `if`, `if-else`, nested decisions, and `if-else-if` structures. They also show Boolean variables and flags, string comparisons, `TryParse` input validation, Windows Forms radio buttons and check boxes, `CheckedChanged` events, `switch` statements, and working with ListBox selections and items.

## Project contents

- **Code-Slides/** contains full-slide PNG screenshots of the slides selected for their code or code expressions.
- **Code-Slides/README.md** explains each screenshot and displays it directly in the page.

The screenshots preserve the original slide layout and content.
