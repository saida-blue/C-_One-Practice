# Chapter 5 Overview — Files, Random Numbers, and the Load Event

This part starts with the presentation section titled “Using Files for Data Storage” and includes the material that follows it.

## Topics

- Text-file input and output with `StreamReader`, `StreamWriter`, and `File` methods
- Reading lines and processing a file until its end
- Opening and saving files with Windows dialog controls
- Generating random integers and floating-point values with `Random`
- Running initialization code in a Windows Forms `Load` event handler

The examples cover opening, reading, writing, appending, and closing files; responding to dialog results; selecting file paths; generating random values; and executing code when a form loads.
