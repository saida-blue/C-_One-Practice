# Chapter 4 Overview — Loops and Increment/Decrement

This part contains the presentation material before the section titled “Using Files for Data Storage.” It focuses on repeating actions with loops and changing counter values.

## Topics

- `while` loops and pretest conditions
- Infinite loops and loop counters
- Increment and decrement operators, including prefix and postfix forms
- `for` loops with initialization, tests, and updates
- `do-while` loops and posttest conditions

The examples show how loop conditions control repetition, how counters can count up or down, and how `do-while` differs from `while` when its condition starts false.
